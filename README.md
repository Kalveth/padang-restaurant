# Dapur Padang

> Masakan dengan rasa yang bikin betah di hati.

Selamat datang di website resmi Dapur Padang, restoran yang menyajikan cita rasa makanan padang dengan bahan dan bumbu segar dan diracik sendiri.

---

## Lembar Konsep Usaha

1. **Jenis Usaha**: Rumah makan
2. **Ciri Khas**: Suasana dapur terbuka dan bumbu racikan sendiri tanpa pengawet.
3. **Lokasi**: Kota Pontianak, Kalimantan Barat
4. **Tahun Berdiri**: 2011
5. **Pendiri**: Kalven Mablevin
6. **Target Pelanggan**: Pelajar, keluarga, dan penyelenggara acara.

### 3 Warna Utama

1. #820909: Warna utama yang memberikan kesan kehangatan dengan warna merah tua yang enak dipandang dan ini juga merupakan warna favorit dari pendiri itu sendiri.
2. #b71c1c: Warna yang menjadi titik fokus mata pengunjung, ini merupakan warna kedua untuk dikombinasikan dengan warna utama.
3. #FFFFA0: Warna kontras dari warna utama, sehingga cocok untuk dijadikan judul pada website jika memiliki latar warna utama.

## Cara Menjalankan Website

1. Buka link github website ini dan download ZIPnya. Link: https://github.com/Kalveth/padang-restaurant.git
2. ekstrak file ZIPnya dan masuk ke dalam folder hasil ekstraknya. Cari index.html dan tekan dua kali untuk membuka di browser langsung.
